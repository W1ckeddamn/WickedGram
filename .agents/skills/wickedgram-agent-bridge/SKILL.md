# WickedGram AI Agent Bridge

Навык взаимодействия с запущенным клиентом WickedGram Desktop через встроенный локальный API мост (`127.0.0.1:40404`).

## Когда применять
- Необходимо проверить статус работы WickedGram Desktop и авторизованного аккаунта.
- Агенту требуется получить список последних чатов или диалогов.
- Агенту требуется прочитать историю сообщений в чате.
- Агенту требуется отправить сообщение, ответ (reply), поставить отметку о прочтении или отправить статус набора текста.
- Агенту необходимо слушать поток входящих сообщений в реальном времени (SSE).

## Когда НЕ применять
- Для изменения исходного кода приложения (используй инструменты редактирования файлов).
- Когда клиент WickedGram не запущен (сначала собери и запусти клиент).
- Для внешних запросов к серверам Telegram напрямую в обход клиента (мост работает только локально с запущенным процессом).

## Требования и окружение
- Запущенный клиент WickedGram (мост включен по умолчанию на `127.0.0.1:40404`).
- Конфигурационный файл `tdata/wickedgram_agent.json` (создается клиентом автоматически) или переданный токен `--token`.
- Python 3 для исполнения `Tools/agent_cli.py` (или `Tools/agent.cmd`).

## Пошаговый регламент

### 1. Проверка доступности моста
```bash
Tools\agent.cmd status --json
```
Убедись, что `bridge_listening: true` и `logged_in: true`.

### 2. Получение списка чатов
```bash
Tools\agent.cmd chats list --limit 20 --json
```

### 3. Чтение сообщений
```bash
Tools\agent.cmd messages get <chat_id> --limit 30 --json
```

### 4. Отправка сообщения
```bash
Tools\agent.cmd messages send <chat_id> "Текст ответа" --json
```
Для ответа на конкретное сообщение:
```bash
Tools\agent.cmd messages send <chat_id> "Текст ответа" --reply-to <message_id> --json
```

### 5. Пометить чат прочитанным
```bash
Tools\agent.cmd messages read <chat_id> --json
```

### 6. Мониторинг новых сообщений в реальном времени
```bash
Tools\agent.cmd events listen --json
```

## Проверка результата
- Все команды возвращают структурированный JSON с полем `"status": "ok"`.
- При отправке сообщения возвращается `"sent": true`.
